# templates/

<!-- template: templates/readme.template.md -->

The shapes the repo's docs and directory READMEs follow. Copy one when
adding a doc or a directory README — the layout is not improvised. Each
template explains itself in an HTML comment at the top, so the finished
file stays clean for readers.

- [`docs.template.md`](docs.template.md) — shape for a content doc under
  `docs/`.
- [`readme.template.md`](readme.template.md) — shape for a directory
  `README.md`.
