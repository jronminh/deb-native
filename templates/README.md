# templates/

> Template: [`readme.template.md`](readme.template.md) (this directory's
> own index follows it). Read this file before touching anything in this
> directory or guessing a file's purpose from its name alone. Add a
> `README.md` like this one whenever a new directory holds more than a
> couple of files that aren't self-explanatory from their names alone.

The two stable formats every `README.md` and every content doc in this
repo follows, so a directory index and a spec/log/guide read the same way
everywhere instead of each inventing its own layout. Copy the matching
file, fill in the placeholders, delete this note.

- `readme.template.md` — for a directory's own `README.md` (`scripts/`,
  `docs/spec/`, `native/`, ...): what the directory is for, then one line
  per file or subdirectory.
- `docs.template.md` — for a content doc (`docs/spec/*.md`,
  `docs/log/*.md`, `docs/guides/*.md`): a summary, a table of contents,
  related docs, then the actual sections.
